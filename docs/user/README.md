## Which page do I need?

- **I just installed it.** [Getting started](getting-started.md).
- **I hear nothing.** [Troubleshooting](troubleshooting.md#no-sound), then run `/sonara:doctor`.
- **Claude asked me something and I do not know how to answer.** [Answering prompts](answering-prompts.md).
- **I want to skip, repeat, mute or flush.** [Hotkeys](hotkeys.md).
- **A key types a strange character, or does nothing.** [Hotkeys](hotkeys.md), then [Troubleshooting](troubleshooting.md#hotkeys-do-not-work-or-clash).
- **It reads too much, or skips code I want.** [Reading and code](reading-and-code.md).
- **I want shorter spoken replies.** [Spoken summaries](summaries.md).
- **I want a different or better voice.** [Voices and engines](voices-and-engines.md).
- **I want to change a number, such as speed or volume.** [Settings](settings.md).
- **I run several Claude Code windows.** [Several sessions](sessions.md).
- **Music pauses or gets quiet.** [Troubleshooting](troubleshooting.md#other-apps-stay-quieter-or-paused), and the Audio page in [Settings](settings.md).
- **I wonder what leaves my PC.** [FAQ](faq.md), then [PRIVACY.md](../../PRIVACY.md).
- **Something else.** [FAQ](faq.md).

## Quick reference

| Need | Do |
|---|---|
| Check that all is well | `/sonara:doctor` |
| Open the settings | `/sonara:settings` |
| Start Sonara again after a stop | `/sonara:start` |
| Remove Sonara | `/sonara:uninstall` |
| Previous or next section | Tap Ctrl+Alt+Up or Down |
| Hear the latest reply again | Hold Ctrl+Alt+Up |
| Flush the rest | Hold Ctrl+Alt+Down |
| Mute | Ctrl+Alt+M |
| Next session | Ctrl+Alt+P |
