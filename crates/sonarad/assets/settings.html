Attention sounds

Your own chimes
–
–

To replace a chime, paste this folder into File Explorer's address bar and put a WAV file there named after the chime: session_change.wav, turn_done.wav, choice.wav, permission.wav, summary_failed.wav, error.wav, nav.wav or nav_edge.wav. Any WAV works (mono or stereo, any sample rate, up to 10 seconds). It plays from the next time that chime sounds; delete the file to get the built-in sound back.

Select a shortcut and press the new keys (Escape cancels), or use × to unbind it. The defaults use Ctrl+Alt, which is AltGr on many European keyboards: if a shortcut warns that it takes a character away, rebind it with Win. A shortcut another program owns has to be changed.
