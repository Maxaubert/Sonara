# The bundled sound of each event (#211): `<event> = <sound>`, where
# <sound> is the name of a WAV in this folder without `.wav`, or `none`
# (the event is silent until the user picks a sound). An event left out
# is silent too.
#

# page's sound picker. Adding or removing a sound is a file change only:
# build.rs scans the folder; a default naming a missing sound fails the
# build. Sound names are lowercase letters, digits, '-' or '_'.
#

# sounds that may be redistributed under this repo's licence.
